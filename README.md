# Sarah - AI 3D English Tutor

Aplicación interactiva de conversación en inglés inspirada en Praktica, con avatar 3D en tiempo real, lip-sync y cerebro impulsado por Google Gemini.

## ✨ Características

- 👩‍🏫 **Avatar 3D interactivo:** Modelo GLB con visemas Oculus y morph targets ARKit para sincronización labial y expresiones naturales.
- ⚡ **Google Gemini:** Diálogo conversacional dinámico y natural.
- 🎙️ **Reconocimiento y síntesis de voz:** Web Speech API integrada en el navegador.
- 💡 **Coaching de pronunciación y gramática:** Detección de errores gramaticales y palabras con trampas fonéticas para hispanohablantes.
- 🌐 **100% Client-Side:** No requiere backend ni servidores GPU costosos; corre directamente en el navegador del usuario.

## 🚀 Uso

1. Abre `index.html` a través de un servidor web local (o visita la URL de GitHub Pages).
2. Introduce tu API Key de Gemini en el modal de Configuración (obtenla gratis en [Google AI Studio](https://aistudio.google.com/)).
3. Pulsa el botón **HABLAR** o presiona la **barra espaciadora** y ¡empieza a practicar!
